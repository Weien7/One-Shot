0ne Shot 是一款俯视角3D赛博朋克美术风格与科幻风格射击游戏。你将扮演一位「清道夫」，负责以高效，绝对且干净利落的方式扫清那些社会中的蛀虫。

「啊……让我们开始吧。」

你具有一个特工必备的精英素质——格斗技巧，百发百中的射击能力，配置完善的装备，还有——电光火石。

你所掌握的能力，将一切将要达到的未来尽收眼底，让所有敌人的挣扎与逃离都化为无意义的哀嚎，随后一击毙命。

「希望这能让你尽兴。」
就这样。以上便是这次作战的任务简报了。
准备好吧，特工……开始清扫。
